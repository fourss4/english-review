# 합성 샘플 (가상 데이터)

실제 랭디 원본의 **형식만** 흉내 낸 가상 데이터입니다. 실제 인물·수업 내용은 포함하지 않습니다.

- `raw/lesson-demo-01/` — 원본 형식 재현 (채팅·코멘트 복사본, 녹음 파일명 규칙)
- `normalized/les_20260101_01/lesson.json` — 위 원본을 파서가 변환했을 때의 **기대 결과**(테스트 정답)

오디오는 저장소 용량·개인정보 문제로 넣지 않습니다. 테스트에서 필요하면 무음 파일을 생성해 사용합니다.
녹음 파일명 규칙 예: `demo_260101_일상 영어 표현 - 3 천천히 하세요.m4a.mp4` (앞의 `<임의>_<YYMMDD>_`는 날짜용 선택 접두어)
