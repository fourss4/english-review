# 이후 단계 지시문 (한 번에 하나씩 사용)

각 단계는 이전 단계 완료 기준을 충족한 뒤 진행합니다.
사용 시 해당 블록만 복사하거나 `@docs/prompts/02-to-08-next-steps.md 의 02단계를 진행해줘`처럼 지시합니다.

---

## 진행 현황
- 01 계획 ✅ / 02 합성 샘플 ✅ / 03 가져오기 ✅ / 04 복습 카드 ✅ / 05 오디오·검색 ✅ / 06 오프라인·백업 ✅(2026-10-02, 배포는 사용자 진행) / 06-1~08 대기

## 02. 스키마 확정 + 샘플 데이터
확정된 /docs/data-spec.md 와 /schema/*.json 기준으로 /samples 에 가상 수업 데이터 2~3건을 만들어줘.
실제 인물·실제 수업 내용은 쓰지 말고, 오디오는 무음 또는 짧은 합성음으로 대체해.
샘플이 스키마 검증을 통과하는 테스트도 함께 작성해줘.

## 03. Importer
내가 제공한 익명화 샘플 구조를 기준으로 원본 → 표준 스키마 변환 파서를 작성해줘.
입력은 mp4 파일 선택 + 코멘트/채팅 붙여넣기 칸 2개. 원문은 source.raw에 보존하고,
변환 결과를 저장 전에 미리보기·수정할 수 있게 해줘. 파일은 크기·형식 검증을 넣어줘.
파싱 실패 시 어떤 파일의 어떤 부분이 문제인지 사용자에게 보여주되, 수업 내용은 로그에 남기지 마.
/samples 기반 테스트 포함.

## 04. 복습 카드 UI (모바일 우선)
새로 배운 표현·오류교정을 카드로 복습하는 화면을 만들어줘.
간격반복은 SM-2(또는 대안을 ADR로 기록)로 구현하고, 복습 기록도 스키마에 맞춰 저장해.
카드는 Anki 호환 TSV로 내보낼 수 있게 해줘. 가져온 텍스트는 모두 이스케이프 처리.

## 05. 오디오 재생 / 구간 반복
수업 녹음 재생, A-B 구간 반복, 재생 속도 조절(0.75/1.0/1.25)을 구현해줘.
구간 북마크는 WebVTT 또는 스키마 내 JSON으로 저장해 이관 가능하게 해줘.
채팅 이력 열람·검색 화면도 이 단계에서 같이 붙여줘.

## 06. PWA 오프라인 + 백업/복원
Service Worker로 앱 셸을 오프라인 캐시하고, 전체 데이터를 ZIP(manifest.json 포함)으로
내보내기/복원하는 기능을 구현해줘. manifest에는 schemaVersion, 생성일, 파일 목록·해시(SHA-256)를 넣어줘.
마지막 백업 후 일정 기간이 지나면 백업을 권하는 안내도 넣어줘(iOS 저장소 정리 대비).

## 06-1. STT (ADR 0003 전제 조건)
브라우저 내 Whisper를 Android에서 20분 녹음으로 시험하는 실험 페이지를 만들고 속도·발열·정확도를 기록해줘.
채택이 어려우면 PC용 /tools/stt(로컬 Whisper → WebVTT) 스크립트를 작성해줘. 결과는 lessons/<id>/transcript.vtt.

## 07. AI 표현 업그레이드 + 연습 3종 (ADR 0003)
docs/decisions/0003-ai-expression-upgrade.md 기준으로 구현해줘.
(1) 스크립트 → /app/prompts/expression-upgrade.md로 프롬프트 생성. 보낼 내용 미리보기, 이름 자동 마스킹, 구간 제외 기능 포함.
(2) AI 결과 JSON 붙여넣기 → generated.schema.json 검증 → 항목별 확인/삭제 후 저장 → 카드 자동 생성.
(3) 연습 3종: 바꿔 말하기 드릴, 상황→표현 카드, OPIc 미니 답변 챌린지(타이머·녹음·체크리스트, 선택적 AI 피드백 프롬프트).
연습 녹음은 MediaRecorder로 기기에만 저장. 모든 연습은 오프라인 동작.

## (구) 07. AI 퀴즈 + STT 실험 — ADR 0003으로 대체됨, 참고용
(1) 수업·퀴즈 유형을 고르면 /app/prompts 템플릿으로 프롬프트를 만들어 복사하고,
AI가 준 JSON을 붙여넣으면 generated.schema.json으로 검증해 저장·풀이하는 화면을 만들어줘.
프롬프트에는 표현·교정·내 예문만 넣고 강사 정보·채팅은 기본 제외.
(2) 브라우저 내 Whisper를 Android에서 20분 녹음으로 시험하는 실험 페이지를 별도로 만들고 측정 결과를 기록해줘.
채택이 어려우면 PC용 /tools/stt(로컬 Whisper → WebVTT) 스크립트를 대안으로 작성해줘.

## 08. 이관 점검
아래를 점검하고 결과를 /docs/migration-check.md 로 정리해줘.
- 브라우저 데이터를 지운 뒤 백업 ZIP만으로 완전히 복원되는가
- README·data-spec·ADR만 보고 다른 개발자/AI 도구가 작업을 이어받을 수 있는가
- Claude 전용 설정(CLAUDE.md 등) 없이도 빌드·실행·테스트가 되는가
- 잔여 보안 위험과 프로토타입 한계
