AGENTS.md를 먼저 읽고, 아래 요구사항으로 구현 계획부터 세워줘. 코드는 아직 작성하지 마.

[배경]
영어회화 앱에서 수업별로 (1) 수업 녹음 파일, (2) 수업 코멘트(새로 배운 표현, 오류 교정),
(3) 수업 채팅 이력을 받는다. 이걸로 복습과 추가 학습을 하는 모바일 웹앱을 만들고 싶다.
상시 서버는 없고, 가끔 파일을 올려두면 오프라인에서도 쓸 수 있어야 한다.
나중에 Claude 대신 다른 도구/서비스를 써도 데이터와 문서가 그대로 이관되어야 한다.

[요구사항]
- 정적 PWA, 데이터는 IndexedDB, 오프라인 우선
- 수업 가져오기(폴더/ZIP), 전체 백업 내보내기/복원(ZIP + manifest)
- 표현·오류교정 복습 카드(간격반복), 녹음 구간 반복 재생, 채팅 검색
- 추가 학습 콘텐츠(퀴즈 등)는 /tools 의 선택형 CLI가 JSON으로 생성, 앱은 읽기만

[질문/확인 먼저]
- 입력 파일 포맷을 모르니, 내가 익명화 샘플을 제공하면 분석부터 하자.
  샘플 요청 시 어떤 파일을 어떻게 익명화해야 하는지 알려줘.
- 모호한 부분은 한 번에 모아서 질문해줘.

[산출물]
1) 아키텍처 개요
2) 데이터 스키마 초안(/docs/data-spec.md, JSON Schema)
3) 단계별 마일스톤(각 단계 완료 기준 포함)
4) 이식성 위험 요소와 대응
5) 녹음 텍스트 변환(STT)이 필요할 경우의 대안 비교(로컬 도구 vs 외부 API)
