# 익명화 샘플 준비 방법

파서를 만들려면 랭디 원본 파일의 **구조**만 필요합니다. 내용은 실제가 아니어도 됩니다.

## 준비할 것 (수업 1~2회분)
| 항목 | 준비 방법 |
|---|---|
| 녹음 | 30~60초만 잘라낸 파일, 또는 같은 형식으로 본인 목소리만 녹음한 대체 파일. 파일명·확장자는 원본 그대로 |
| 코멘트 | 받은 그대로의 형태(텍스트/PDF/이메일 본문)로 저장하되 아래 치환 규칙 적용 |
| 채팅 | 내보내기 파일 또는 복사한 텍스트. 줄바꿈·시간 표기·화자 표기는 **원본 그대로** 유지 |
| 화면 캡처 | 파일로 받을 수 없는 항목만 캡처하고, 이름·프로필 사진은 가림 처리 |

## 치환 규칙
- 강사 이름 → `T01`, 내 이름 → `ME`
- 이메일·전화번호·계정 ID·회사명 → `[MASKED]`
- 사적인 대화 내용 → 같은 길이의 아무 영어 문장으로 교체해도 됨
- **바꾸지 말 것**: 시간 표기 형식, 화자 구분 기호, 구분선, 제목 형식, 파일 인코딩

## 추가 확인
- 녹음 파일 속성(메타데이터)에 이름이 들어 있을 수 있으니 확인 후 제거
- 샘플은 Langdy 폴더 안 `private/raw-samples/`에 두세요(.gitignore 대상)
- 랭디 약관에서 녹음 파일을 저장·가공할 수 있는 범위를 확인해 주세요
