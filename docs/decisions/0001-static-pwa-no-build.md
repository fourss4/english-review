# ADR 0001: 정적 PWA, 빌드 단계 없이 시작

- 상태: 제안 (사용자 승인 대기)
- 일자: 2026-10-02

## 맥락
상시 서버가 없고, 오프라인 사용이 필요하며, AI 도구나 개발자가 바뀌어도 이어서 작업할 수 있어야 한다.

## 결정
- HTML + ES Modules + JSDoc 타입으로 작성하고 번들러 없이 시작한다.
- 런타임 의존성은 ZIP 처리용 1개(`fflate` 후보)로 제한한다. 도입 전에 버전·라이선스·알려진 취약점을 확인해 이 문서에 기록한다.
- 테스트 도구(dev 전용)는 Node 내장 `node:test`를 우선 쓰고, 스키마 검증 테스트에만 `ajv`를 검토한다.

## 결과
- 장점: 설정 파일이 적어 이관이 쉽고, 정적 호스팅에 폴더를 그대로 올리면 된다.
- 단점: 규모가 커지면 타입 안정성과 모듈 관리가 불편할 수 있다. 그때 Vite + TypeScript 전환을 별도 ADR로 결정한다.
