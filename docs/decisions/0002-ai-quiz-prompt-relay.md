# ADR 0002: AI 추가 퀴즈는 "프롬프트 복사 → 결과 붙여넣기" 방식

- 상태: 일부 대체됨 — 전달 방식은 유지, 생성 내용(퀴즈)은 [ADR 0003](./0003-ai-expression-upgrade.md)으로 대체
- 일자: 2026-10-02

## 맥락
- 상시 서버 없음, Android 단독 사용, 특정 AI 공급자에 종속되지 않아야 함
- API 키를 브라우저나 저장소에 두면 유출 위험이 있음

## 결정
1. 앱에서 수업(또는 기간)을 고르고 퀴즈 종류를 선택하면 **프롬프트 텍스트**를 만들어 클립보드에 복사한다.
2. 사용자는 아무 AI 채팅 서비스에 붙여넣고, AI가 돌려준 JSON을 앱의 "AI 결과 가져오기" 칸에 붙여넣는다.
3. 앱은 `schema/generated.schema.json`으로 검증한 뒤 저장한다. 실패하면 어느 필드가 틀렸는지 보여준다.
4. 프롬프트에 포함하는 정보는 **새 표현·교정 문장·내 예문만**. 강사 별칭, 채팅 원문, 녹음은 기본적으로 제외한다(옵션으로 채팅 포함 가능, 포함 시 경고 표시).
5. 프롬프트 템플릿은 `/app/prompts/*.md` 파일로 관리해 앱 코드 수정 없이 개선할 수 있게 한다.

## 프롬프트 템플릿 골격
```
너는 영어 학습 퀴즈 출제자다. 아래 [학습 항목]만 사용해 퀴즈 {N}문항을 만들어라.
- 유형: {multiple_choice | fill_blank | translate | fix_sentence}
- 난이도: {easy | normal | hard}
- 출력: 아래 JSON 형식만, 설명 문장·코드블록 표시 없이
{generated.schema.json 예시}

[학습 항목]
{expressions / corrections JSON}
```

## 결과
- 장점: API 키·서버·비용 관리 불필요, 공급자 교체가 즉시 가능, 데이터 전송 범위를 사용자가 직접 통제
- 단점: 복사·붙여넣기 수작업이 2회 필요, AI가 형식을 어기면 재요청 필요
- 보완: 대량 생성이 필요해지면 같은 프롬프트 템플릿을 쓰는 PC용 CLI(`/tools/generate`)를 선택적으로 추가
