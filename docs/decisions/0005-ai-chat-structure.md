# ADR 0005: 기호 없는 채팅은 "AI로 교정 찾기"(복사·붙여넣기)로 보완

- 상태: 채택 (사용자 요청, 2026-10-02)
- 관련: ADR 0002(AI 연동은 복사·붙여넣기), ADR 0003(한국어 뜻 채우기)

## 맥락
- 규칙 기반 변환기(`langdy-v1`)는 채팅의 ❌ ✅ 💡 기호로 교정을 찾는다.
- 선생님에 따라 기호를 쓰지 않으면 교정이 0개가 되고, 복습 카드도 만들어지지 않는다.
- 선생님마다 형식이 달라 규칙을 계속 늘리는 방식은 샘플 없이는 추측이 된다.

## 결정
1. 규칙 변환을 먼저 하고, **교정이 0개이면서 채팅이 있으면** 미리보기에서 "AI로 교정 찾기"를 펼치고 추천 표시를 한다(언제든 수동으로도 사용 가능).
2. 앱은 AI를 직접 호출하지 않는다. `app/prompts/chat-structure.md` 템플릿에 채팅·코멘트 원문을 넣은 요청 문장을 만들어 사용자가 원하는 AI에 붙여넣고, 답변을 다시 붙여넣는다.
3. 보내기 전 처리: 이메일·전화번호·URL·@아이디·긴 숫자 자동 가림 + 사용자가 지정한 단어(선생님 이름 등, 기기에 기억) 가림. 전달될 전문을 화면에 보여 준다.
4. 결과 처리(`app/js/ai-structure.js`, 형식 `schema/lesson-structure.schema.json`):
   - 코드블록·앞뒤 설명이 섞여도 JSON만 추출
   - 알 수 없는 필드 제거, 길이·개수 제한, 틀린 문장/교정이 빠진 항목 제외
   - 기존 항목과 합칠 때 같은 교정(틀린 문장 유사도 0.85 이상)·같은 표현은 추가하지 않고 **비어 있는 칸만** 채움. 사용자가 입력한 값은 덮어쓰지 않음
   - 한국어 뜻(`meaning`, 예문 `ko`, 교정 `naturalKo`)을 같은 요청에서 받아 영↔한 카드가 바로 생기게 함
   - 수업에 `source.aiAssisted {at, provider}` 기록
5. 저장 전 사용자 확인 단계를 유지하고, 미리보기에 "교정 직접 추가 / 표현 직접 추가" 버튼을 둔다(AI 없이도 보완 가능).

## 결과
- 장점: 선생님별 형식 차이에 대응, API 키·서버·비용 없음, AI 교체 자유.
- 단점: 복사·붙여넣기 2회. 채팅 내용이 외부 AI로 전달됨(가림 처리로 완화, 전송 범위는 사용자가 확인).
- 한계: AI가 강사 문장을 학습자 문장으로 오인하거나 교정을 빠뜨릴 수 있음 → 저장 전 확인 필수. 선생님이 이유를 쓰지 않은 교정은 AI가 쓴 이유 앞에 "(AI)"가 붙음.
- 같은 선생님 형식이 반복되면 실제 샘플을 받아 규칙 변환기에 형식을 추가하는 것을 우선한다(AI 없이 처리되므로).
