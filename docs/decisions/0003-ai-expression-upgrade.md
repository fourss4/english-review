# ADR 0003: AI 기능을 "OPIc IH 표현 업그레이드 3선 + 연습 3종"으로 변경

- 상태: 제안 (사용자 승인 대기)
- 일자: 2026-10-02
- 관계: ADR 0002의 **전달 방식(프롬프트 복사 → 결과 붙여넣기)은 유지**하고, **생성 내용(퀴즈)을 이 문서로 대체**

## 맥락
사용자 요청: 녹음 내용 중 OPIc IH 수준에서 알아야 할 slang, idiom, 더 좋은 영어 표현으로 바꿀 수 있는 문장·단어를
설명·예시와 함께 3개 제시하고, 이를 익숙해질 때까지 연습하는 기능 3개를 추가한다.

## 결정

### 1. AI 생성물: 수업당 "표현 업그레이드 3선"
| 필드 | 내용 |
|---|---|
| category | `slang` / `idiom` / `better_expression` |
| original | 내가 실제로 말한 문장 또는 단어 (녹음 스크립트에서 인용) |
| originalOffsetSec | 해당 발화의 녹음 위치(스크립트 타임스탬프 기준, 알 수 없으면 생략) |
| suggestion | 바꿔 쓸 표현 |
| meaningKo | 한국어 뜻 |
| explanation | 왜 더 자연스러운지, 뉘앙스, 주의점(무례하거나 지나치게 캐주얼한 경우 포함) |
| register | `casual` / `neutral` / `formal` |
| examples | 예문 2~3개 (영문 + 한국어 해석) |
| situationKo | 이 표현을 써야 하는 상황을 한국어로 한 문장 (연습 2에 사용) |
| opicQuestion | 이 표현을 활용할 수 있는 OPIc형 질문 1개 (연습 3에 사용) |

- 기본 3개, 설정에서 1~5개로 조정 가능
- 같은 표현이 이전 수업에서 이미 나왔으면 앱이 "복습 중인 표현"으로 표시하고 중복 카드를 만들지 않음

### 2. 연습 기능 3종 (모두 오프라인 동작)
| # | 기능 | 진행 방식 | 기대 효과 |
|---|---|---|---|
| 1 | **바꿔 말하기 드릴** | ① 내 원래 발화 구간을 녹음에서 재생 → ② 업그레이드 표현으로 소리 내어 다시 말하며 녹음 → ③ 모범 문장 공개, 내 녹음과 번갈아 듣기 → ④ 자기평가(SM-2) | 내 실제 말버릇을 직접 교정 |
| 2 | **상황 → 표현 떠올리기 카드** | 한국어 상황(`situationKo`)만 보고 표현을 말하거나 입력 → 정답·예문 공개 → SM-2 간격반복에 편입. 회차가 쌓이면 빈칸 예문, 예문 듣고 따라 말하기(기기 TTS)로 단계 상승 | 필요한 순간에 표현이 바로 나오게 함 |
| 3 | **OPIc 미니 답변 챌린지** | `opicQuestion` 제시 → 60~90초 답변 녹음(타이머) → 체크리스트: 목표 표현 사용 / 묘사·경험·의견 구조 / 연결어 사용 → 선택: 내 답변을 스크립트로 옮겨 AI 피드백 프롬프트 복사 | 표현을 실제 시험 답변 맥락에서 사용 |

- 3개 연습을 모두 마치면 해당 표현은 "익숙함" 단계로 올라가고, 이후 간격반복 주기로만 다시 나옴
- 연습 녹음(내 목소리)은 기기에만 저장하며 백업 ZIP 포함 여부는 설정으로 선택

### 3. AI에 보내는 데이터 범위
- 녹음 스크립트(STT 결과)가 원천. 스크립트가 없으면 채팅·교정 문장으로 대체 생성(정확도 낮음 안내)
- 앱이 **보낼 내용을 미리보기로 보여주고**, 이름·연락처 패턴은 자동 마스킹, 구간을 빼고 보낼 수 있게 함
- 기본 STT(Whisper)는 화자를 구분하지 못하므로, 내 발화와 강사 발화를 AI가 문맥으로 추정함 → 결과에서 `original`이 강사 문장으로 잘못 잡힐 수 있음. 저장 전 사용자가 확인·삭제
- 음성 파일 자체는 AI에 보내지 않음

## 영향
- STT가 이 기능의 사실상 전제 조건이 됨 → STT 일정이 M6에서 M5 직후로 앞당겨짐
- `generated.schema.json`에 `kind: expression_upgrade`, `items[].type: upgrade` 추가
- 프롬프트 템플릿: `/app/prompts/expression-upgrade.md`
- 기존 AI 퀴즈 프롬프트는 제거. 오프라인 규칙 기반 복습(카드, 문장 고치기, 빈칸, 객관식)은 그대로 유지

## 보완 (2026-10-02): 한국어 뜻 자동 채우기
랭디 원본(채팅·코멘트)은 영어로만 되어 있어 한국어 뜻이 없다(`docs/sample-analysis.md` 4장). 사용자 결정에 따라:
- 같은 프롬프트에서 기존 표현·교정의 한국어(`meaningKo`, `situationKo`, `examplesKo`, `naturalKo`)를 함께 요청한다.
- 결과의 `koFills[]`를 앱이 `ref`(exp_/cor_ id)로 찾아 **비어 있는 칸만** 채운다. 사용자가 직접 쓴 값은 덮어쓰지 않는다.
- 녹음 스크립트가 없어도 이 부분만 따로 실행할 수 있다(`items: []`).
- 한국어가 채워지기 전에는 한→영 카드·상황 카드는 출제하지 않는다.

## 미확인 사항
- OPIc IH 수준 판단은 AI의 일반 지식에 의존하며 공식 채점 기준과 일치한다고 보장할 수 없음
- Android 기기 TTS(음성 합성)의 오프라인 영어 음성 품질은 기기마다 다름
