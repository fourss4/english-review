# ADR 0007: 복습 문제 유형·간격 재설계, 오답 복습, 백업 축소

- 상태: 채택 (2026-10-02, 사용자 피드백 반영)

## 결정
1. **문장 통째로 쓰기(fix) 제거.** 문제 유형은 빈칸(cloze, 짧은 표현만 입력), 고르기(choice), 뜻·쓰임 떠올리기(meaning, 자기 평가), 상황 보고 표현 고르기(situation).
2. **카드 = 학습 항목 1개**(교정·표현·업그레이드). 복습 때마다 그 항목의 문제 유형을 돌아가며 낸다.
3. **간격(srs2, SM-2 변형):** 처음 맞히면 어려움 1일 / 보통 3일 / 쉬움 5일. 이후 어려움 ×1.2, 보통 ×ease, 쉬움 ×ease×1.3(최소 +1일, 어려움<보통<쉬움이 최소 1일씩 차이 나도록 보정). 다시 = 오늘 다시(세션 끝에 재출제), ease −0.2. ease 범위 1.3~3.0.
   - 기존 SM-2는 첫 두 번 간격이 버튼과 무관하게 1일·6일이라 "모두 1일 후"로 보이는 문제가 있었다.
4. **자동 채점:** 고르기·빈칸은 앱이 채점. 틀리면 자동으로 "다시"로 기록하고 해설 표시, 맞으면 어려움/보통/쉬움 중 선택. 빈칸은 오타 대비 "정답으로 인정" 버튼.
5. **오답 복습:** 틀린 기록이 있는 카드를 수업과 관계없이 모아, **마지막으로 틀린 유형과 다른 유형**으로 다시 낸다. 오답 복습에서 맞히면 오답 표시 해제.
6. **백업 축소:** 녹음 포함 전체 백업 ZIP·복원·14일 알림 제거. 수업 내용은 PC의 수업 패키지로 다시 가져올 수 있으므로, 휴대폰에만 있는 **학습 기록(카드의 간격·풀이 이력)만 JSON으로 내보내기/가져오기**한다(`schema/progress.schema.json`).
7. 수업 화면에서 구간 저장·내 목소리 녹음 제거. 녹음 재생(속도·±5초)과 스크립트 보기(줄을 누르면 해당 위치 재생)만 유지. 강사 총평 칸 제거(총평 속 교정·표현은 처리기가 추출).
