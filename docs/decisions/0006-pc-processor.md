# ADR 0006: PC "수업 처리기"로 녹음 텍스트 변환·AI 정리를 미리 수행

- 상태: 채택 (2026-10-02, 사용자 결정: Python·ffmpeg 설치 가능, Claude API 사용, 공급자 교체 가능해야 함)
- 대체: ADR 0002·0005의 "앱 안 복사·붙여넣기"는 예비 경로로 격하. ADR 0003의 표현 업그레이드는 이 처리기에서 생성

## 맥락
- 사용자는 수업 파일을 직접 고치지 않고, 녹음까지 텍스트로 바꿔 AI가 정리한 결과를 바로 복습하고 싶다.
- 강사마다 채팅 형식(이모지 유무)이 달라 규칙 기반 변환은 한계가 있다.
- 상시 서버는 없고, 앱은 휴대폰에서 오프라인으로 동작해야 한다.

## 결정
1. **처리는 PC에서, 복습은 휴대폰에서.** `tools/`의 Python 처리기가 `private/inbox/<수업폴더>`의 녹음·채팅·코멘트를 읽어 `private/out/lesson-<id>.zip`(수업 패키지)을 만든다. 앱은 패키지를 가져오기만 한다.
2. **녹음 → 텍스트는 PC 로컬에서**(faster-whisper). 녹음은 외부로 보내지 않는다.
3. **AI 정리는 공급자 인터페이스 뒤에.** `tools/processor/llm/`에 `anthropic`(기본, Messages API), `openai_compat`(OpenAI 호환 API), `manual`(복사·붙여넣기), `mock`(테스트)을 둔다. 공급자·모델은 `tools/config.toml`에서 바꾸고 키는 환경변수(`ANTHROPIC_API_KEY` 등)로만 받는다. 프롬프트는 `tools/prompts/*.md` 파일이라 코드 수정 없이 고칠 수 있다.
4. **AI 호출 2회:** ① 추출 — 교정(없으면 AI가 교정·자연스러운 표현 생성, `ai` 표시), 표현, 내 말 대신 쓸 slang/idiom/better expression **정확히 3개** ② 연습 — 항목마다 2가지 이상 유형의 문제(빈칸·고르기·뜻 떠올리기·상황), 다음 수업 준비 노트, OPIc 모의 질문.
5. 보내기 전 이메일·전화·URL·지정 이름 가림. 결과는 JSON Schema(`schema/lesson.schema.json` v2)로 검증하고, 실패하면 오류를 알려 1회 재요청한다.
6. 주간 요약: `weekly` 명령이 최근 7일 수업 결과를 모아 `weekly-<연도>W<주>.zip`을 만든다.

## 결과
- 장점: 강사 형식과 무관, 녹음 기반 표현 업그레이드 가능, 앱은 계속 서버 없이 동작, AI 교체 가능.
- 단점: PC 설치 필요, API 비용(사용량에 따라, 확인 필요), 처리 결과를 휴대폰으로 옮기는 수작업 1회.
- 위험: Whisper는 화자를 구분하지 않아 AI가 내 말·강사 말을 문맥으로 추정 → 앱에서 항목 숨기기 제공. AI 결과는 틀릴 수 있음(검토 전제).
- 실제 수업 파일·중간 결과·API 응답은 모두 `private/`(GitHub 업로드 금지 폴더)에만 저장한다.
